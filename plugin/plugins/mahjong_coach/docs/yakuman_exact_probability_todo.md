# 役满精算引擎（后续 TODO）

当前 `yakuman.py` 的职责是即时路线距离与有时间预算的 Monte Carlo 估算。它按当前可见牌扣除后的未知牌均匀抽样，最多运行 10,000 次或 250ms；结果不包含对手放铳，并明确属于近似值。

后续独立实现精算引擎时，再纳入以下范围：

- 用组合枚举或动态规划计算牌山耗尽与条件概率；
- 精确处理副露、暗杠、加杠、四杠子和不同规则；
- 建模对手摸切、手牌阻断、放铳与鸣牌行为；
- 将点数、顺位、场况和风险效用纳入路线取舍；
- 区分四麻、三麻、天和/地和与累计役满；
- 输出可复核的状态空间、误差来源和性能基准。

上述内容不属于 0.3.0 三阶段反馈优化的验收条件。
