## 3. 当前运行链

```text
截图
  -> 结算边界检测
  -> 牌桌定位/校准
  -> 手牌、副露、牌河、按钮识别
  -> 多帧状态合并
  -> 开局/检查点/操作窗口/防守判断
  -> 本地策略与打牌排序
  -> 浮窗和插件详情页
```

明确结算的小局边界是：

```text
playing
  -> settlement_candidate（第 1 帧）
  -> settlement_latched（第 2 帧）
  -> 冻结上一局手牌/副露/牌河/策略
  -> awaiting_next_round
  -> 12 至 14 张无副露新手牌连续稳定两帧
  -> playing
```

如果没有拍到结算画面，仍保留旧版间接兜底：

```text
旧牌河已有内容
  -> 当前牌河归零
  -> 新手牌连续稳定
  -> 间接确认新局
```
